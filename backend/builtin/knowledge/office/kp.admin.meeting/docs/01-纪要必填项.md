# 会议与纪要规范 — 纪要必填项

## 适用范围

适用于公司内部所有正式会议，包括部门例会、项目例会、跨部门协调会、董事会、客户会议等。

## 纪要结构

1. **会议基本信息**：主题、时间、地点、参会人、缺席人、记录人；
2. **议题清单**：按议程顺序逐项记录；
3. **决议**：每项议题的最终结论与达成共识；
4. **动作项**：负责人、截止日期、可验证产出；
5. **遗留事项**：未决问题与下次会议跟进安排。

## 必填项

| 字段 | 说明 |
| --- | --- |
| 主题 | 简短明确，含项目代号或场景 |
| 时间 | 起止时间（含日期） |
| 参会人 | 部门+姓名，缺席人注明原因 |
| 议题 | 编号 + 标题 |
| 决议 | 一句话明确结论，必要时附数据 |
| 动作项 | 负责人 + 截止日 + 验收标准 |
| 风险与延期 | 与计划偏离的事项 |

## 写作规范

- **第三人称**记录，**不掺杂个人意见**；
- **决议必须明确**（"同意/不同意/延期/继续讨论"）；
- **动作项使用动词开头**（"提交""确认""上线"等）；
- **金额、日期、客户名**等关键信息须复述参会人表述；
- **争议未决事项**单列"遗留事项"，不要混入决议。

## 分发规则

- 纪要在会后 **1 个工作日内**发出；
- 通过 OA / 邮件 / 飞书分发至参会人与缺席人；
- 抄送直属部门负责人与项目 owner；
- 客户会议纪要经项目经理审核后对外发出。

## 红线

- **不得事后**篡改已发出的纪要；如需更正须发"补充说明"；
- **决议需经参会人确认**后方可发出；
- **客户敏感信息**按公司《保密制度》执行。

## 常见问答

- **Q：纪要要写多少字？**
  A：常规例会 800-1500 字，重大项目可至 3000 字。
- **Q：录音是否必备？**
  A：客户会议强制录音；内部会议不强制。
- **Q：跨时区会议纪要语言？**
  A：默认中文；客户为外资时附英文版。
- **Q：纪要丢失怎么办？**
  A：通过 OA 备份恢复；备份缺失的须重写并注明。
