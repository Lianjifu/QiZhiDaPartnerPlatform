# 会议与纪要规范 — 会议分发规则

## 适用范围

适用于公司内部会议纪要的发送范围、保密级别、归档与检索。

## 分发层级

- **主线（CP1）**：参会人 + 缺席人 + 直接业务关联方；
- **次线（CP2）**：部门负责人 + 项目 owner；
- **旁线（CP3）**：公司公告渠道（仅决议摘要）。

## 分发渠道

| 会议类型 | 渠道 | 时效 |
| --- | --- | --- |
| 部门例会 | 飞书群 + OA 公告 | 1 工作日 |
| 项目例会 | 项目群 + 邮件 | 1 工作日 |
| 跨部门协调会 | 飞书群 + 邮件 + OA 公告 | 1 工作日 |
| 董事会 | 加密邮件 + 物理归档 | 当日 |
| 客户会议 | 邮件 + CRM 附件 | 2 工作日 |

## 保密级别

- **公开**：决议摘要可对外披露；
- **内部**：仅限参会人查阅；
- **机密**：仅参会人 + 项目 owner 查阅；
- **绝密**：纸质 + 加密，阅后即焚。

## 归档

1. 纪要发出后 1 个工作日内由会议主席归档至 OA「会议档案」模块；
2. 归档时标注：项目代号、会议类型、保密级别、关联文档；
3. 归档期限：**内部 3 年 / 机密 5 年 / 绝密 10 年**；
4. 重大项目会议纪要同步归档至合同管理系统。

## 检索

- 通过 OA 会议档案按"项目代号 / 日期 / 部门 / 关键词"检索；
- 仅限有权限人员查阅对应保密级别；
- 检索日志留存 90 天。

## 红线

- **不得在群聊中转发**机密级纪要原文；
- **不得在未授权渠道**（微信、朋友圈）发布决议内容；
- **客户会议纪要**未经项目经理审核不得对外发布；
- **涉及人事/法务/财务**的决议须脱敏后再分发。

## 常见问答

- **Q：能否给非参会人补发纪要？**
  A：可以，须由会议主席或项目 owner 审批，并按保密级别同步通知。
- **Q：多久后可以销毁会议纪要？**
  A：按保密级别到期后由法务与档案员联合销毁。
- **Q：客户会议纪要双语吗？**
  A：默认中文；客户为外资时附英文摘要。
- **Q：紧急决议如何处理？**
  A：可在纪要发出前先发送"决议快报"，24 小时内补发完整纪要。
