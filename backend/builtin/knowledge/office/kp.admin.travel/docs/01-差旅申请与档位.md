# 差旅与报销标准 — 差旅申请与档位

## 适用范围

适用于公司因公出差的所有员工（含实习生），出差类型含客户拜访、项目驻场、培训、展会、行业会议等。

## 出行前申请

1. 出差前 2 个工作日提交《出差申请单》至直属经理；
3. 跨省出差须部门负责人审批；
4. 海外出差须副总裁以上审批；
5. 出差申请未通过的差旅费用不予报销。

## 交通档位

| 行程 | 标准 |
| --- | --- |
| 同城往返（≤100 km） | 公共交通 |
| 城际（≤800 km） | 二等座高铁 / 经济舱 |
| 城际（>800 km） | 二等座高铁 / 经济舱 |
| 海外短途（≤5h） | 经济舱 |
| 海外长途（>5h） | 商务舱（仅 VP 及以上） |

## 住宿档位

| 城市等级 | 单晚上限 |
| --- | --- |
| 一线城市 | 600 元 |
| 省会及重点城市 | 450 元 |
| 其他城市 | 350 元 |

## 出差补贴

- 餐补：100 元/日（按实际行程天数计）；
- 杂费：30 元/日（含市内交通、行李等）；
- 招待客户用餐：单次不超过 500 元，超标事前申请。

## 红线

- 跨档位升级须事前特批，不接受事后追补；
- 与客户同行的招待费用须注明客户姓名、人数与事由；
- **不得使用私人里程/积分**换取的机票冲账。

## 常见问答

- **Q：临时出差来不及事前申请怎么办？**
  A：口头/微信报备直属经理 + 2 个工作日内补单，逾期不予追补。
- **Q：同行人数不同的住宿档位如何折算？**
  A：单人出差按上限；多人合住可合并使用单晚预算，但单人不超过 1.5 倍上限。
- **Q：出差当天往返是否计补贴？**
  A：行程跨越 12:00 计 1 日餐补，跨越 18:00 计 1 日杂费。
