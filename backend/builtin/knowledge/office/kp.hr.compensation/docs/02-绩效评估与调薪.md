# 薪酬与绩效规则 — 绩效评估与调薪

## 适用范围

适用于公司全员（含管培生），不含试用期员工首月评估。

## 评估周期

- **月度**：关键结果指标（KR）跟进；
- **季度**：360 评估 + 业务结果回顾；
- **年度**：综合绩效 + 长期激励归属触发评估。

## 绩效等级

| 等级 | 占比建议 | 含义 |
| --- | --- | --- |
| S（卓越） | 5%-10% | 远超预期，作为晋升候选 |
| A（优秀） | 20%-30% | 超额完成 |
| B（达标） | 50%-60% | 完成核心指标 |
| C（待改进） | 5%-10% | 部分指标未达 |
| D（不达标） | <5% | 启动辅导或调岗 |

## 评估流程

1. **自评**：员工提交本周期工作成果与反思（1 个工作日）；
2. **同事反馈**：每季度随机抽取 5 位同事 360 反馈；
3. **直属经理打分**：综合业务结果与协作评价（3 个工作日）；
4. **跨部门校准**：HRBP 主持部门间相对评估（1 个工作日）；
5. **结果沟通**：经理与员工 1-on-1 沟通绩效结果与发展建议；
6. **申诉**：员工对结果有异议的可在 5 个工作日内提起申诉。

## 调薪与晋升关联

| 绩效 | 调薪建议 | 晋升资格 |
| --- | --- | --- |
| S | 8%-15% 或立即晋升 | 直接进入晋升池 |
| A | 5%-10% | 可进入晋升池 |
| B | 3%-6% | 视岗位空缺 |
| C | 0%-2% | 否 |
| D | 不调 | 启动辅导或调岗 |

## 红线

- 不得在评估期内临时修改目标；
- 不得跨部门对比未校准数据；
- 不得以主管偏好取代事实评价。

## 常见问答

- **Q：连续两个季度 C 怎么办？**
  A：进入绩效改进计划（PIP），60 天未达 B 即转岗或协商离职。
- **Q：绩效评估会影响年终奖吗？**
  A：年终奖以年度绩效系数 × 公司业绩系数计算，与季度等级正相关。
- **Q：跨部门合作的项目怎么评估？**
  A：在《项目角色评估表》中由项目负责人打分，占本人绩效 30%。
