# 报价单与合同模板 — 合同模板与签署

## 适用范围

适用于公司对外签署的销售合同、订阅协议、服务水平协议（SLA）、保密协议（NDA）。

## 标准合同类型

| 类型 | 适用 | 必含条款 |
| --- | --- | --- |
| 订阅协议 SaaS | 在线订阅产品 | 服务期限、续费、终止 |
| 永久授权 License | 一次性买断产品 | 知识产权、责任限制 |
| 服务协议 | 实施 / 培训 / 咨询 | 工作范围、交付物、验收 |
| SLA | 服务等级承诺 | 等级指标、补偿、违约 |
| NDA | 双方保密 | 保密范围、期限、违约责任 |

## 签署流程

1. **预审**：合同类型确认后从模板库调取对应版本；
2. **填充**：商务条款按报价单写入，红色字段必须填写；
3. **法务审**：非标准条款须法务审，3 个工作日内出具意见；
4. **审批**：按合同金额分层审批（参考授权矩阵）；
5. **签署**：线下或电子签（推荐电子签，电子签存档 PDF + 公证）；
6. **归档**：合同正本归档至合同管理系统，复印件交付客户；
7. **触发交付**：CRM 自动触发实施与计费流程。

## 模板版本

- 模板按季度更新一次；
- 旧版合同仍按签署时版本执行；
- **重大法律变更**（如《数据安全法》新增）触发即时更新。

## 红线

- 不得使用过期模板；
- 不得擅自删除 SLA 或责任限制条款；
- 不得在客户要求下口头变更已签字条款；
- **跨境合同**须法务、合规部门双审。

## 常见问答

- **Q：客户坚持要修改 SLA 怎么办？**
  A：法务评估可调整范围；超出公司标准的服务等级须 VP 审批并独立计费。
- **Q：电子签法律效力？**
  A：通过第三方电子签平台签署的合同与中国《电子签名法》要求一致，与手写签名具有同等法律效力。
- **Q：合同争议如何处理？**
  A：合同条款优先；条款未约定的，按《合同法》一般规定执行；重大争议由法务发起仲裁或诉讼。
