# 营销内容与渠道 SOP — 渠道发布与复盘

## 适用范围

适用于所有对外营销渠道的发布节奏、效果监测与数据复盘。

## 渠道归口

| 渠道 | 责任人 | 内容类型 |
| --- | --- | --- |
| 公众号 | 内容运营 | 深度文、行业观察 |
| 官网 | 内容运营 + 产品 | 产品介绍、案例、白皮书 |
| 视频号 / 抖音 | 短视频运营 | 产品演示、客户证言 |
| 知乎 | KOL 合作组 | 行业问答、长文 |
| 行业媒体 | PR 组 | 公司动态、人物专访 |
| 邮件 | 客户成功 | 客户案例、活动邀请 |

## 发布流程

1. **预热**：发布前 3 天提交预热排期；
2. **审核**：法务、合规、品牌三审通过；
3. **排期**：CMS 排期系统登记发布时间；
4. **发布**：按排期自动发布，手动触发须运营负责人签字；
5. **存档**：原始素材归档至 DAM 系统，保留 3 年。

## 数据指标

| 渠道 | 核心指标 |
| --- | --- |
| 公众号 | 阅读、分享、关注转化 |
| 官网 | UV、CTA 点击、表单提交 |
| 视频号 | 完播、点赞、关注 |
| 知乎 | 赞同、收藏、回答采纳 |
| 邮件 | 打开率、点击、退订 |

## 复盘节奏

- 周一例会：上周内容表现；
- 月度复盘：渠道投资回报率（ROI）；
- 季度复盘：内容主题与季度业务目标对齐；
- 重大活动（展会、发布会）：活动后 7 天内复盘。

## 红线

- **不得未经审批**发布涉及产品定价、未来路线图的内容；
- **不得在节假日**自动发布重大公告；
- **不得跨境渠道**未经法务审的内容。

## 常见问答

- **Q：渠道排期冲突怎么办？**
  A：按优先级：重大活动 > 产品发布 > 日常内容。冲突时由营销负责人协调。
- **Q：数据造假如何处置？**
  A：禁止任何形式的数据造假行为，按《员工守则》第 12 条处理。
- **Q：跨部门联合发布？**
  A：双方负责人联签，预热与发布节奏对齐。
