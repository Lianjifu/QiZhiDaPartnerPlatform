# 营销内容与渠道 SOP — 内容选题与生产流程

## 适用范围

适用于公众号、官网、抖音、视频号、白皮书、案例研究、展会物料等内容资产的策划、生产与发布。

## 选题立项

1. 周一营销例会确定季度主题与本月节奏；
2. 内容策划人提交选题卡：目标读者、核心信息、CTA；
3. 部门负责人审批立项，重大选题（涉及品牌、产品发布）须法务审核；
5. 选题卡归档至 CMS 系统。

## 内容生产

| 角色 | 责任 |
| --- | --- |
| 选题人 | 选题卡 + 大纲 |
| 主笔 | 初稿 |
| 内容审 | 事实、数据、品牌口径核查 |
| 法务 | 涉合规、客户案例、合同条款的复核 |
| 设计 | 视觉与排版 |
| 终审 | 营销负责人最终签字 |

## 生产节奏

- 公众号：**周二、周五 19:00** 推送；
- 官网案例：**每月 1-2 篇**；
- 视频号 / 抖音：**每周 1 条**；
- 白皮书：**季度**发布，与季度主题绑定；
- 展会物料：展会前 **30 天**完成首版。

## 品牌口径

- 一律使用全称"企智搭 · 数字伙伴平台"或"QiZhiDa · PartnerPlatform"，不得缩写为"QZDA"以外的简称；
- 产品能力名称以官网"能力地图"为准；
- 客户案例须脱敏且经客户书面授权；
- 对外数字指标须引用最近一次公司公告或招股说明书。

## 红线

- **不得披露未公开财务数据**与客户名单；
- **不得对比同行**贬损式表述；
- **不得承诺未交付的产品能力**；
- **重大事实性数据**须经首席财务官签字。

## 常见问答

- **Q：内容能否 AI 生成？**
  A：可以使用，但最终稿必须人工复核事实、品牌口径与合规。
- **Q：客户案例授权范围？**
  A：以客户书面授权为准；超出范围须重新申请。
- **Q：失败案例能否发布？**
  A：内部复盘可以，对外发布须隐藏客户身份且经合规审批。
