# IT 自助服务 — 权限申请说明

## 适用范围

适用于系统访问权限、数据查询权限、API Key、生产环境操作权限等所有 IT 类权限的申请、变更与回收。

## 权限分类

| 类型 | 示例 | 默认审批层级 |
| --- | --- | --- |
| 业务系统 | CRM、HR、ERP | 直属经理 + 系统 owner |
| 数据查询 | 数据库只读、报表导出 | 直属经理 + 数据 owner + 法务 |
| API 接入 | 第三方 API Key、SDK Token | 直属经理 + 安全团队 |
| 生产环境 | 服务器 SSH、K8s 操作 | 部门负责人 + SRE Lead |
| 高权限 | 财务、人事、审计 | 副总裁 + 法务 |

## 申请流程

1. OA「权限申请」模块提交申请单；
2. 注明权限名称、用途、必要性、到期日；
3. 直属经理审批合理性；
4. 系统 owner / 数据 owner 审批权限范围；
5. 法务/合规审批（涉敏感数据）；
6. IT 执行开通并通知申请人；
7. 权限到期前 7 天自动提醒续期或回收。

## 临时权限

- 默认权限有效期 90 天，到期自动回收；
- 临时权限须写明到期日；
- 延期需重新提交申请；
- 项目结项后 7 个工作日内回收全部临时权限。

## 权限回收

| 场景 | 触发 | 回收 |
| --- | --- | --- |
| 离职 | HR 提单 | 离职日 17:00 冻结 |
| 转岗 | HR 提单 | 旧权限 3 日内回收 |
| 项目结项 | PM 提单 | 结项后 7 日内回收 |
| 违规 | 安全团队通报 | 立即冻结 + 调查 |

## 红线

- **不得在申请单中隐瞒**权限实际用途；
- **不得为他人申请**自己不使用的权限；
- **不得绕过申请流程**通过技术手段获取；
- **生产环境权限**严禁远程共享；
- **违规访问、滥用权限**按《信息安全规范》第 8 条处理。

## 常见问答

- **Q：申请被拒怎么办？**
  A：通过 OA 查看拒绝理由；可补充材料后重新申请或申诉。
- **Q：跨部门权限怎么申请？**
  A：发起部门审批 + 接收部门系统 owner 双签。
- **Q：能否自己修改权限？**
  A：严禁；权限变更必须经审批流程。
- **Q：权限审计频率？**
  A：每季度全量审计；高风险权限月度审计。
- **Q：临时权限可以延期吗？**
  A：可延期 1 次；超过须重新评估。
