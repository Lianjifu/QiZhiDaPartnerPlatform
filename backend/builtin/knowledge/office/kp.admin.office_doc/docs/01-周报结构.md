# 公文与材料规范 — 周报结构

## 适用范围

适用于全体员工（含试用期与管培生）的周报提交，部门/项目组级周报参照本规范执行。

## 提交流程

1. 每周五 17:00 前完成本周工作记录；
2. 周一 09:30 前完成上周总结与本周计划；
3. 通过 OA 提交周报至直属经理；
4. 直属经理 24 小时内批阅；
5. 月底汇总作为月度复盘材料。

## 必备字段

| 字段 | 说明 |
| --- | --- |
| 本周完成 | 已交付的工作成果，含可量化指标 |
| 风险与阻塞 | 当前遇到的问题与需要的支持 |
| 下周计划 | 下周重点事项与里程碑 |
| 学习与反思 | 本周学到的方法、工具、思考 |

## 写作要点

- **标题**："【周报】姓名 / 项目代号 / YYYY-MM-DD 至 YYYY-MM-DD"；
- **完成事项**用动词开头（"完成""上线""发布""对接"等）；
- **数据**以"数字 + 单位"形式表达（"完成 12 篇""节省 6 人日"）；
- **风险**按"问题 + 影响 + 需要的支持"三段式；
- **计划**按"事项 + 负责人 + 截止日"三段式。

## 红线

- **不得简单罗列事项**，必须给出量化结果；
- **不得隐瞒风险**，主动暴露问题并请求资源；
- **不得流于形式**，机械重复上周内容；
- **不得代写**，由员工本人填写。

## 常见问答

- **Q：跨部门合作项目怎么写？**
  A：单独成段标注协作方与产出。
- **Q：周报提交晚了怎么办？**
  A：当月累计 2 次以上将影响绩效评估；3 次以上进入谈话。
- **Q：周报可否合并写？**
  A：不允许；每人独立提交。
- **Q：周报长度要求？**
  A：常规 500-1000 字；项目经理/总监 800-1500 字。
