# 公文与材料规范 — 通知写作

## 适用范围

适用于公司内部通知、公告、通报、请示、批复、函件等公文类材料的写作与发布。

## 通知结构

1. **标题**：发布单位 + 主题 + 文种；
2. **主送**：接收对象（部门 / 群组 / 个人）；
3. **正文**：背景、目的、要求、时限；
4. **落款**：发布单位、发布日期；
5. **附件**：相关文件、表格、流程图。

## 写作规范

- **标题**：使用"关于..."的介词结构，避免"通知通知"；
- **主送**：明确"全体 / 部门 / 角色"，避免"有关人员"等模糊表达；
- **正文**：开门见山，先说结论再展开背景；
- **要求**：使用可执行动词（"请""须""应"），避免"建议""最好"；
- **时限**：明确日期或时间窗口（"自发布之日起 5 个工作日内"）；
- **联系人**：注明姓名 + 工号 + 联系方式。

## 文种选择

| 文种 | 用途 |
| --- | --- |
| 通知 | 部署工作、传达事项 |
| 公告 | 公开事项、重大变更 |
| 通报 | 表彰、批评、警示 |
| 请示 | 申请审批、请示事项 |
| 批复 | 对请示的批准或不同意 |
| 函 | 跨部门、对外协作 |

## 审批流程

- 部门内部通知：部门负责人审批；
- 跨部门通知：发起部门 + 相关部门会签；
- 全公司公告：副总裁以上审批；
- 涉密事项：法务 + 合规联合审批。

## 发布渠道

- 内部公告：飞书群 + OA 公告 + 邮件；
- 部门通知：部门群 + OA 部门公告；
- 紧急通知：电话 + 短信 + 飞书群同步。

## 红线

- **不得使用口语化表达**（"你们""我们"），使用"全体员工""各部门"；
- **不得发布未经审批**的通知；
- **不得伪造**发布日期、落款；
- **涉及个人奖惩**的通知须经本人确认。

## 常见问答

- **Q：通知附件有哪些格式要求？**
  A：仅限 PDF、DOCX、XLSX；单个附件 ≤ 10MB。
- **Q：跨语言通知怎么处理？**
  A：默认中文；外籍员工集中的部门提供英文版。
- **Q：通知撤销如何处理？**
  A：发布"撤销声明"，原通知标红"已撤销"并保留备查。
- **Q：紧急通知能否后补审批？**
  A：可以，发布后 1 个工作日内补全审批流程。
