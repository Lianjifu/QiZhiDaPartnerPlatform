# M10 · 记忆中心

> **模块 ID**：M10 · **路由**：`/memory` · **后端前缀**：`/api/memory/*`、`/api/evolve/*` · **实现度**：✅
> 导航：[← 索引](./README.md) · 上一模块 [M09 技能中心](./M09-技能中心.md) · 下一模块 [M11 消息渠道](./M11-消息渠道.md)

**功能**：数字伙伴运行记忆分层治理，并向知识中心输送候选。

### 前端

`features/memory/components/` — `MemoryPage.tsx`（壳）+ `MemoryTab.{Overview,Records,Candidates,Governance}` + `MemoryDetail.tsx`。
所有请求经 `frontend/web/src/services/query.ts` 的 `useApiQuery` / `useApiMutation` 发出，该层自动注入 `currentWorkspaceId`（默认 `w1`）到 `x-workspace-id` 头。

### 后端

`internal/memory/`（`service.go` 薄转发 · `handlers.go` · `handlers_candidates.go` · `handlers_refinement.go` · `vectorstore.go` · `helpers.go` · `identity/`）+ evolve 候选路由落在 `internal/copilot/copilot_evolve.go`。

## 边界

- 长期记忆只形成**知识候选**，不直通权威知识；需在知识中心审核入库
- `?q=` 语义召回依赖 pgvector；记录数 < 5k 时顺序扫描足够（见 `vectorstore.go` 头注释）
- 写路径需同时满足 admin 角色与零信任放行，非 admin 一律 `E_MEMORY_WRITE_FORBIDDEN`
