# M11 · 消息渠道

> **模块 ID**：M11 · **路由**：`/channels` · **后端前缀**：`/api/channel-control/*`、`/api/channel/*/events/*` · **实现度**：✅

### 前端

- 厂商 SDK — `internal/feishu/client.go` + `feishu/webhook.go` · `internal/wecom/client.go` · `internal/dingtalk/client.go` · `internal/weixin/client.go`
- 部署与投递控制 — `internal/server/handlers_channels.go` · `internal/server/handlers_channel_webhooks.go` · `internal/server/handlers_feishu_webhook.go` · `internal/server/handlers_d.go`
