# M08 · 知识中心

> **模块 ID**：M08 · **路由**：`/knowledge` · **后端前缀**：`/api/knowledge/*` · **实现度**：✅ ◐ 语义检索
> 导航：[← 索引](./README.md) · 上一模块 [M07 模型服务](./M07-模型服务.md) · 下一模块 [M09 技能中心](./M09-技能中心.md)

**功能**：企业知识资产全链路——入库、加工、检索评测、图谱与引用治理。**以知识包为中心组织**。

> ⚠️ **编号提示**：`internal/knowledge` 的包注释仍写着「M07 知识中心」——M07/M08 换号前的历史遗留。**模块号以本目录与 `role-nav.ts` 为准**：M07 = 模型服务，M08 = 知识中心。

### 前端

`features/knowledge/components/` — `KnowledgePage.tsx`（目录页，渲染 `KnowledgeTab.Packages`）+ `useKnowledgeController.ts`（主数据层）+ `KnowledgePackagePage.tsx` / `KnowledgePackageCreatePage.tsx`（包内工作台）+ `KnowledgeDocPage.tsx` · `KnowledgeSourcePage.tsx` · `KnowledgeUploadPage.tsx` + `KnowledgeStudioRail.tsx`（向导轨）· `PackageWorkbench.tsx` · `ProcessingWorkbench.tsx` · `KnowledgeModals.tsx`。

**知识包生命周期（6 步，`knowledge-ui.ts:115` 的 `PACKAGE_LIFECYCLE_STEPS`）**：

```text
01 基本信息 → 02 添加内容 → 03 加工处理 → 04 检索验证 → 05 知识图谱 → 06 发布上线
```

包状态机：`draft → review（加工中）→ published（已发布）→ deprecated / archived`（`knowledge-ui.ts:100-113`）。

### 后端

`internal/knowledge/`（`service.go` 门面 · `handlers.go` · `handlers_packages.go` · `handlers_sources.go` · `handlers_jobs.go` · `handlers_eval.go` · `builtin.go` · `helpers.go` · `compat.go`）。

## 边界

- 完整向量检索需 `qzda-rag:8092` sidecar；无 sidecar 时为关键词降级，不提供语义召回，响应标 `degraded: true`
- 图谱为加工产物的展示视图，非独立图数据库
- 发布有召回率门禁：`recall < 50` 拒绝
