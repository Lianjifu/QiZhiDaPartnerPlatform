# M04 · 工作区

> **模块 ID**：M04 · **路由**：`/workspaces` · **后端前缀**：`/api/workspaces/*` · **实现度**：✅
> 导航：[← 索引](./README.md) · 上一模块 [M03 任务中心](./M03-任务中心.md) · 下一模块 [M05 数字伙伴](./M05-数字伙伴.md)

**功能**：业务域工作区的控制面——资源、环境发布、配额成本。**不重复**建设权限/零信任/审计面。

### 前端

`frontend/web/src/pages/Workspaces.tsx`（路由 `App.tsx:80`，限 `admin`）；另有 `layouts/AppLayout.tsx:69` 调 `GET /api/workspaces` 供顶栏切换器使用。

### 后端

M04 **未抽独立包**，全部在 `backend/internal/server/`：`handlers_a.go`（列表 / 创建 / 子资源 / 动作）+ `handlers_workspaces_publisher.go`（publisher key）+ `internal/store/default_workspace.go`（稳定壳工作区 `w1`）。

## 错误码

`E_WORKSPACE_WRITE_FORBIDDEN` · `E_WORKSPACE_NAME_REQUIRED` · `E_WORKSPACE_OWNER_REQUIRED` · `E_WORKSPACE_IN_USE` · `E_WORKSPACE_NOT_FOUND` · `E_WORKSPACE_SCOPE` · `E_ROLE_FORBIDDEN` · `E_NOT_FOUND` · publisher-key 的字面量 `E_CONFLICT`（未在 `pkg/errors` 定义）。

## 边界

- 跨工作区引用一律拒绝；`x-workspace-id` 不可伪造（见 [附录 B §B.9](./附录B-运行模式与本地起停.md#b9-工作区-header-不可伪造)）
- `workspaceSubresource` 里的 `agents` / `tools` 走的是通用子资源分支，未做伙伴 / 工具专属投影
