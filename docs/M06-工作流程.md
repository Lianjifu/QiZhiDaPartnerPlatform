# M06 · 工作流程

> **模块 ID**：M06 · **路由**：`/workflows` · **后端前缀**：`/api/workflows/*`、`/api/workflow-templates/*`、`/api/workflow-skills/*` · **实现度**：✅ ◐ Temporal 可选
> 导航：[← 索引](./README.md) · 上一模块 [M05 数字伙伴](./M05-数字伙伴.md) · 下一模块 [M07 模型服务](./M07-模型服务.md)

**功能**：可视化编排业务执行路径，校验发布后可绑定为技能。

### 前端

`features/workflows/components/` — `WorkflowsPage.tsx`（5 Tab）+ `useWorkflowsController.ts`（主数据层）+ `WorkflowStudioPage`（React Flow 画布）+ `WorkflowTemplatePreviewPage` + `WorkflowOrchestrationSessionPage`（AI 辅助编排会话）+ `WorkflowsTab.{List,EDITOR,Skills,Runs,Settings,Generation}` + `version-diff.ts`（版本 Diff）。

| Tab key | 能力 |
|---|---|
| `templates` | **平台内置**（办公通用 `wf.office.*` + 部门模板）与 **个人创建**（`wft-user-*`）；默认筛「办公通用」 |
| `canvas` | React Flow 画布编排 |
| `publishSkill` | 受控发布为流程技能，进入技能中心 |
| `history` | 运行记录 |
| `versions` | 版本 Diff（只读核查视图，`auditor` 默认落此） |

### 后端

`internal/workflows/`（`service.go` 门面 · `handlers.go` · `handlers_runs.go` · `handlers_skills.go` · `handlers_templates.go` · `orchestration.go`）+ `internal/qzdaworkflow/`（`engine.go` · `temporal.go` · `activities.go`）。

## 边界

- Temporal 为**可选依赖**，默认走进程内本地引擎；本地引擎不是分布式持久化执行
- `CallTrialActivities`（`internal/qzdaworkflow/activities.go:16`）在试运行时探测 `QZDA_AGENT_RUNTIME_URL` 与 `QZDA_RAG_URL` 的 `/healthz`，产出 `runtime_invoke:ok|fallback|skipped` 步骤——两个 sidecar 未起时流程仍可跑，但步骤标记为 skipped
