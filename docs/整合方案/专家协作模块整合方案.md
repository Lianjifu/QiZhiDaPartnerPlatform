## 一、背景与目标

### 1.1 背景

M02 专家协作是平台的对话核心。代码当前形态:

- **前端**:`pages/Copilot.tsx` 单文件 **4382L —— 超 TSX ≤400L 门禁 ~11 倍**(本次最大痛点);业务子模块已在 `features/copilot/` 散开,但页面聚合仍是单体
- **后端**:20 个 `copilot_*.go` 文件全部在 `internal/server/`(共 ~6.4K LOC),与 `auth/`、`operations/` 形成对比 —— M01 / M02 / M03 已分别成包
- **微服务**:`backend/services/qzda-collab/` 仅有脚手架(doc.go × 9,`cmd/qzda-collab/main.go`,`SERVICE.md`),handler 全部留在 monolith

`pages/Copilot.tsx` 单文件 4382L 是核心阻力 —— 它包含 SSE 流读取、专家上下文组装、消息渲染、Composer、turn 状态机、artifacts、slash commands、文档预览等全部逻辑;**必须先拆再合**。

### 1.2 目标

- **前端**:`grep frontend/web/src/features/copilot/`(含 pages/Copilot.tsx 拆分后)能找全所有 M02 代码
- **后端**:`grep backend/internal/copilot/` 能找全所有 M02 handler + 业务 + 注册
- **行为零变化**:SSE 流形状、turn 状态机、expert context 选型算法、artifact 渲染、rate limit、mock 数据形状、audit 文案全部保留
- **为未来抽 `qzda-collab` 微服务铺路**:`internal/copilot/` 自包含,不依赖 `*Server`(与 `auth` / `operations` 一致)

### 1.3 不在范围内

| 项 | 说明 |
|---|---|
| 实现 `services/qzda-collab/` handler | 本次只重排 monolith 代码;不创建真服务 |
| 拆 CopilotTurn 状态机 | 拆页面 / 搬 handler 已是大动作;Turn 内部逻辑本次保留 |
| 抽取 Copilot 专属 Zustand store | 当前 M02 无 Zustand store(状态全在 TanStack Query + useRef inline),**不引入新状态层** |
| 重写 SSE 流协议 | 现有 stream 客户端 + `/api/copilot/conversations/{id}/stream` 行为不变 |
| 改 expert 选型算法 | `expert-tools` / `expert-suggestions` / `expert-context` 算法不变 |
| 重命名 `copilot` → `collab` | 路由前缀 + 协议名 + 客户端类名都以 `copilot` 命名,跨系统耦合,不重命名 |
| 拆 `turn-narrative/` 子系统 | 7 文件子目录已自包含,作为单元整体保留 |
| 重写 mock 数据 | mock 形状不变 |

### 5.4 `handler.go` 接口设计

```go
package copilot

import (
    "net/http"
    "time"
)

// CopilotStore is the read/write surface needed by copilot_*.go.
// server/ wires this to *store.Store. Minimum required — only methods
// actually called by the 20 copilot_*.go files.
type CopilotStore interface {
    RLock()
    RUnlock()
    Lock()
    Unlock()
    AppendAudit(workspaceID, actorName, action, category, status, detail string)
    CopilotConversations(cid string) (*Conversation, bool)
    SaveCopilotConversation(*Conversation)
    // ... etc — read existing copilot_*.go to enumerate
}

// RateLimiter is the per-turn / per-session rate limiter.
type RateLimiter interface {
    Allow(workspaceID string) bool
}

// AuditSink is the optional audit sink (nil skips audit).
type AuditSink func(workspaceID, actor, action, target, status, detail string)

// Handler holds all HTTP handlers for /api/copilot/* and /api/internal/copilot/*.
type Handler struct {
    Store        CopilotStore
    RateLimiter  RateLimiter
    AuditSink    AuditSink
    // 配置 / secrets
    Now          func() time.Time
}

func (h *Handler) Routes() []Route

// 8 HTTP wrappers:
func (h *Handler) ListConversations(r *http.Request) (any, error)
func (h *Handler) CreateConversation(r *http.Request) (any, error)
func (h *Handler) GetCopilotTurnStatus(r *http.Request) (any, error)
func (h *Handler) ReplayCopilotTurn(r *http.Request) (any, error)
func (h *Handler) CancelCopilotTurn(r *http.Request) (any, error)
func (h *Handler) CopilotStream(r *http.Request) (http.Handler, error) // SSE
func (h *Handler) CopilotMessageFeedback(r *http.Request) (any, error)
func (h *Handler) CopilotPostTurnAPI(r *http.Request) (any, error)
```
