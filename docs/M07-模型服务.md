# M07 · 模型服务

> **模块 ID**：M07 · **路由**：`/models` · **后端前缀**：`/api/model-providers/*`、`/api/model-routing/*`、`/api/models/*` · **实现度**：✅
> 导航：[← 索引](./README.md) · 上一模块 [M06 工作流程](./M06-工作流程.md) · 下一模块 [M08 知识中心](./M08-知识中心.md)

**功能**：供应商接入、路由策略、发布回滚、故障演练与模型审计。

> ⚠️ **编号提示**：`internal/models` 的包注释仍写着「M08 模型中心」——这是 M07/M08 换号前的历史遗留。**模块号以本目录与 `role-nav.ts` 为准**：M07 = 模型服务，M08 = 知识中心，M10 = 记忆中心。

### 前端

`features/models/components/` — `ModelsPage.tsx`（3 Tab）+ `useModelsController.ts`（主数据层）+ `ModelProviderCreatePage` / `ModelProviderDetailPage` + `ModelsTab.{Providers,Governance,Audit}` + `ModelsModals.{ProviderForm,ProviderDetail,Confirm,Drill,Policy}`。

| Tab key | 能力 |
|---|---|
| `access` | 供应商接入、凭据引用（掩码）、连通性校验、模型发现 |
| `governance` | 运行健康、预算占用、地域分布；隔离范围验证已发布路由的降级链 |
| `audit` | 接入、校验、发布、回滚、退役与演练结果追溯 |

### 后端

`internal/models/`（`service.go` 门面 · `handlers.go` · `handlers_routing.go` · `handlers_invoke.go` · `handlers_stream.go` · `handlers_aliases.go` · `require.go`）+ `internal/modelprov/`（`chat.go` · `probe.go` · `ssrf.go` · 凭据与地域解析）。

字段级契约（枚举取值、凭据落库口径、关键响应形状）见 [`backend/api/models-contract.md`](../backend/api/models-contract.md)——M0 冻结的模型服务契约，改动前先对那里。

## 边界

- 生产态凭据以 AES-256-GCM 加密入库（`QZDA_CREDENTIAL_KEY`）；配置 Vault 时优先写入 Vault（`internal/vault`）
- `discover-models` 与 `test-connection` 受每分钟 30 次的限流约束
- 供应商 base URL 必须过 `modelprov.ValidateBaseURL` SSRF 校验
