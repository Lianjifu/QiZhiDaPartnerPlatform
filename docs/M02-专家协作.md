# M02 · 专家协作

> **模块 ID**：M02 · **路由**：`/copilot` · **后端前缀**：`/api/copilot/*`、`/api/conversations/*`、`/api/model-invoke*` · **实现度**：✅ ◐ RAG sidecar
> 导航：[← 索引](./README.md) · 上一模块 [M01 运营总览](./M01-运营总览.md) · 下一模块 [M03 任务中心](./M03-任务中心.md)

**功能**：与已上岗数字伙伴协同处置；会话、工具、证据、审批与审计一体化。

### 前端

`features/copilot/` — `components/CopilotPage.tsx`（壳）+ 三栏（`CopilotPage.SessionsAside` / `Conversation` / `ContextAside`）+ `Composer` / `ExpertPicker` / `MessageBubble` / `ToolCallRow` / `ApprovalCard` / `ArtifactCard` / `DocumentPreview`（docx·slides·spreadsheet）/ `Share` / `Feedback` / `Handoff` / `VariantNav`；状态在 `useCopilotController` · `useCopilotState` · `useCopilotEffects` · `useCopilotActions`；流式客户端 `lib/copilot-stream.ts`；断线恢复 `lib/pending-turn-recovery.ts`。

### 后端

`internal/copilot/`（16k 行）— `service.go`（`Service` + `Deps` 门面）·（HTTP 路由只在 `server.go` 的 route switch 一处；包内测试用的路由夹具在 `handler_test.go`，不进生产构建）· `copilot_harness.go` · `copilot_react.go` · `copilot_plan.go` · `copilot_multi.go` · `copilot_live_stream.go` · `copilot_tools.go` · `copilot_thought.go` · `copilot_reflect.go` · `copilot_snapshot.go` · `copilot_evolve.go` · `copilot_ratelimit.go` · `copilot_turn_state.go` · `mcp_client.go` · `shell_tools.go` · `web_tools.go`。

> ⚠️ **实现位置说明**：M02 的**路由与部分真实实现仍在 `internal/server/`**（`handlers_c.go`、`handlers_copilot_variants.go`），`internal/copilot/` 持有域逻辑与 façade。查 M02 代码时两个目录都要看。

## 边界

- RAG 依赖 `qzda-rag:8092` sidecar；不可达时降级为已发布语料的关键词匹配，并在响应中标记 `degraded: true`
- 高风险写操作需双签 + 零信任决策后才落地
- **回合后记忆写入的锁契约**：协作回合结束、`copilotStream`（`internal/server/handlers_c.go:902`，此时仍持 `Store.Lock()`）会调 `server.ingestRuntimeMemoryLocked`（`internal/server/server.go:2207`）→ `memory.Service.IngestRuntimeMemoryLocked`（`internal/memory/service.go:236`，**不加锁**版本）。是否写入由 `copilot.ShouldIngestTurnMemory`（`internal/copilot/types.go:360` → `copilot_context.go:747`）判定：有工具调用 / 会话消息 ≤2 条 / 消息数 %4==0 / 文本 ≥400 字 即为真，因此**新会话的前 1–2 轮基本必写**
- M02 的 HTTP 路由只有一份：`server.go` 的 route switch。包内集成测试用的路由夹具（`internal/copilot/handler_test.go`）只在测试构建里存在——历史上它曾放在生产文件 `internal/copilot/handler.go` 中，导致同一批路径有两处声明、需手工同步，已迁出
