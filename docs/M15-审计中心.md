# M15 · 审计中心

> **模块 ID**：M15 · **路由**：`/settings?tab=auditCenter` · **后端前缀**：`/api/audit-center*` · **实现度**：✅
> 导航：[← 索引](./README.md) · 上一模块 [M14 持续验证](./M14-持续验证.md)

**功能**：授权范围内只读追溯；脱敏证据包导出。

### 前端

`frontend/web/src/pages/AuditCenter.tsx`（路由 `/audit-center`；`App.tsx` 对 admin 重定向到 `/settings?tab=auditCenter`，auditor 直达）。

### 后端

`internal/server/handlers_a.go` 的 audit 路由族（`auditCenter` · `auditExport`）+ `internal/store/store.go:318` `AppendAudit` 审计钩子 + `internal/infra/auditpg.go`（PG 落库 sink）+ `internal/infra/opensearch.go`（可选检索 sink）。

## 落库总表

| 渠道审计 | `platform.kv_documents` | collection `channel_audit`（整表替换） |
| 零信任事件 | 内存态 | `Store.ZTEvents`，非 DurableCollections |
| 检索索引 | OpenSearch（可选） | `QZDA_OPENSEARCH_URL` 未配置时该路数据源缺席 |

## 角色语义

- `auditor` 持 `audit.read` / `audit.export`，**不参与决策与执行**
- 但**签署位仍可按策略参与高风险会签**——只读 ≠ 不可签（见 [M13](./M13-访问控制.md) 的 `maybeHoldForCountersign`）

## 边界

- 导出当前**只登记意图**，不生成实际 zip 文件（`downloadAvailable: false`）
- `ZTEvents` 不持久化，重启后零信任事件流不保留
- OpenSearch 为可选依赖，未配置时事件列表少一路来源
