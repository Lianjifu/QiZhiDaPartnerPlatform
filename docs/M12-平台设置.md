# M12 · 平台设置

> **模块 ID**：M12 · **路由**：`/settings` · **后端前缀**：`/api/tenant/*`、`/api/billing/*`、`/api/backups/*`、`/api/api-keys`、`/api/webhooks-config` · **实现度**：✅
> 导航：[← 索引](./README.md) · 上一模块 [M11 消息渠道](./M11-消息渠道.md) · 下一模块 [M13 访问控制](./M13-访问控制.md)

**功能**：租户级设置壳，聚合组织运营与三项安全治理入口。

### 前端

`features/settings/components/` — `SettingsPage.tsx`（路由壳：Tab 切换 + URL 持久化，`?tab=<key>`）+ 5 个 Tab 面板 + 3 个嵌入式治理面板。

| Tab key | 中文 | 能力 |
|---|---|---|
| `tenant` | 组织信息 | 租户档案、席位/伙伴配额条、通知订阅 Toggle |
| `security` | 身份认证 | SSO/MFA/会话说明卡 + 身份摘要条 |
| `backup` | 数据保留 | 备份列表、立即备份、恢复语义 |
| `apikeys` | 开发集成 | API Key、Webhook |
| `billing` | 套餐用量 | 方案、月费、Token/席位/伙伴配额进度 |
| `access` | 访问控制 | 嵌入 [M13](./M13-访问控制.md) |
| `zeroTrust` | 持续验证 | 嵌入 [M14](./M14-持续验证.md) |
| `auditCenter` | 审计中心 | 嵌入 [M15](./M15-审计中心.md) |

### 后端

`internal/settings/`（`service.go` 门面 · `handlers_billing.go` · `handlers_backups.go` · `handlers_notif.go` · `handlers_tenant.go` · `handlers_apikeys.go` · `handlers_webhooks.go` · `helpers.go`）。

`internal/settings` **不 import `internal/server`**——跨包能力全部经 `settings.Deps` 注入（`service.go:39`：`WorkspaceID` / `IdentityFrom` / `DecodeMap` / `AppendAudit` / `PersistCollection` / `ActorIsAdmin` / `EvaluateWrite`）。

### 备份与恢复演练

| 环节 | 位置 |
|---|---|
| 前端 | `SettingsPage.tsx:59` + `SettingsTab.Backup.tsx:24` `GET /api/backups` |
| 路由 | `server.go:1310-1314` → `s.settingsSvc.ListBackups` · `RequestBackup` · `BackupAction`（`service.go:95` · `:100` · `:105`） |
| Handler | `internal/settings/handlers_backups.go:16` `listBackups` · `:31` `requestBackup` · `:57` `backupAction` |
| 校验 | `listBackups`：仅 admin 或持 `audit.read`；`requestBackup`：仅 admin；`backupAction`（approve / reject / restore-drill）：走 `s.evaluateWrite(r, "backup", action, policy.Input{ApproverID: id.ID})` → 申请人自批被拒；`restore-drill` 要求备份状态已为 approved |
| 落库 | 写 `Store.Backups`(status=pending_approval) → `persistCollection("backups", …)` → `platform.kv_documents`；`appendAudit` |
| 错误码 | `apperr.AdminRequired`、`apperr.RoleForbidden`、`apperr.SODSelfApproval`、`apperr.BadRequest`（「仅已批准备份可演练恢复」） |
